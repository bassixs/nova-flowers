# FLEURÉ — демо-сайт премиального цветочного салона

Демонстрационный сайт-магазин цветочного салона. Первый экран — название салона, внутри букв
которого видно фото пионов; при прокрутке камера «пролетает» сквозь букву и фото раскрывается.
React + Vite + TypeScript + GSAP ScrollTrigger + SVG-маска. Публикация — GitHub Pages.

**Сайт:** https://bassixs.github.io/nova-flowers/

> Это демо: контакты, цены, условия доставки и отзывы — пример наполнения. Заказы не отправляются.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173/nova-flowers/
npm run build      # сборка в dist/
npm run preview    # просмотр production-сборки
```

## Публикация на GitHub Pages

Уже настроено: `.github/workflows/deploy.yml` собирает проект и публикует его при каждом push в `main`.

1. Settings → Pages → Build and deployment → Source: **GitHub Actions** (включено).
2. `git push` в `main` → вкладка Actions → «Deploy to GitHub Pages» → через 1–2 минуты сайт обновится.
3. Base path задан в `vite.config.ts` (`/nova-flowers/`). Для собственного домена соберите с
   `VITE_BASE=/` и добавьте `public/CNAME`.

## Структура

```
src/

    site.ts      название, контакты, мессенджеры, навигация, SEO, демо-режим
    theme.ts     палитра (CSS-переменные) и цвета процедурного цветка
    catalog.ts   букеты, цены, категории, размеры и множители цены
    delivery.ts  зоны и стоимость доставки, интервалы, преимущества
    content.ts   тексты первого экрана, факты, поводы, шаги заказа, о мастерской, отзывы, FAQ, финал
  components/    Hero, Header, Collection, BouquetModal, Cart (+форма), Sections
  hooks/         useRevealSystem (единая система появлений), useDialog (модальность)
```

## Структура страницы

1. **Первый экран** — название-«окно», одна понятная фраза, кнопки «Выбрать букет» / «Как заказать»
   и 4 факта (цена от, срок доставки, фото перед отправкой, часы работы).
2. **Каталог** — ровная сетка, фильтр по типу, цена за размер M, кнопка «В корзину» на каждой карточке.
3. **Поводы** — 5 плиток, клик фильтрует каталог.
4. **Как заказать** — 3 шага.
5. **О мастерской**, 6. **Доставка** (зоны и цены), 7. **Отзывы**, 8. **Вопросы** (FAQ), 9. финал и подвал.

## Первый экран — как устроено

SVG-маска: молочная вуаль с «вырезанными» буквами `site.brand` поверх полноэкранного фото
(`hero.image` в `content.ts`). Буквы проявляются по очереди, фото внутри букв слегка следует за
курсором. При прокрутке секция закрепляется на ~1.4 экрана: информация уходит, буквы
увеличиваются в 26 раз вокруг точки внутри штриха второй буквы («пролёт»), вуаль растворяется, на
фото построчно появляется заголовок. Название меняется в одном месте и автоматически
растягивается на ширину экрана; на узких экранах буквы вытягиваются по вертикали.
При `prefers-reduced-motion` — статичное название с фото внутри, без закрепления.

## Анимации

- Первый экран: появление букв, параллакс фото за курсором, пролёт сквозь букву, заголовок на фото.
- Заголовки секций: построчное раскрытие из-под маски + blur→sharp.
- Фото: раскрытие clipping-маской, параллакс; финал — раскрытие фото из «окна» на весь экран.
- Карточки: zoom фото, «Подробнее», раскрывающаяся кнопка «В корзину», перестройка при фильтре.
- Микро: заливка кнопок, подчёркивания ссылок, бургер→крестик, меню-шторка, аккордеон FAQ,
  счётчик корзины, модалки/ящик, тосты, галочка успеха.

## Функциональность

Адаптивная навигация и мобильное меню, якорные переходы, фильтр каталога + фильтр по поводу,
карточка букета (размеры S/M/L, количество), корзина в localStorage, оформление с валидацией
и маской телефона, демо-подтверждение, Esc/клик по фону/focus trap/возврат фокуса, тосты,
skip-link, семантическая разметка, мета-теги и schema.org.

## Интеграция заказов

`src/services/orders.ts`: интерфейс `OrderAdapter`. Сейчас активен `demoAdapter` (ничего не
отправляет). Для Telegram / MAX / CRM реализуйте адаптер, который шлёт заказ на **ваш**
сервер или serverless-функцию — токены ботов и CRM нельзя хранить в статическом фронтенде.

## Адаптация под конкретный салон

| Что | Где |
|---|---|
| Название, город, контакты, соцсети и мессенджеры, SEO | `src/config/site.ts`, `index.html` |
| Палитра | `src/config/theme.ts` |
| Букеты, цены, состав, категории, размеры | `src/config/catalog.ts` |
| Доставка: зоны, цены, интервалы, преимущества | `src/config/delivery.ts` |
| Тексты, поводы, этапы, отзывы, финал | `src/config/content.ts` |
| Фото | `public/images/<имя>-800.webp` и `-1600.webp` |
| Фото внутри названия на первом экране | `hero.image` в `content.ts` |
| Отправка заказов | `src/services/orders.ts` |

## Ограничения

- Фото — Unsplash (лицензия допускает коммерческое использование); для реального клиента лучше
  собственная съёмка его букетов. Список источников: docs/CREDITS.md.
- Нет бэкенда, оплаты и админки каталога — каталог редактируется в конфиге.
